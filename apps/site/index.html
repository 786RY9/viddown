Pick the quality by its real size

Paste a link and viddown lists every format the site offers, with the actual file size next to each one. You know what 4K will cost before you start. Want only the sound? Take the audio as an MP3.

Cut out just the part you want

Set a start and an end time and viddown downloads only that stretch. A 90-second moment from a three-hour stream takes seconds, not an hour.

  • Runs on your device

    Videos come down over your own connection and land in a folder you choose. There's no sign-in and no account to make.

  • A queue that resumes

    Paste several links and they download side by side. If your connection drops, each one picks up where it stopped.

  • Keeps up when sites change

    The download engine, yt-dlp, updates itself in the background, so a site changing its player rarely breaks anything for long.

  • About 1,800 sites

Questions

Is it really free?

Yes. There are no ads, no paid tier and no account. The code is open source, so you can read it, build it yourself or change it, on GitHub.

Is it safe? Why does my computer warn me?

The installers aren't code-signed yet. Signing certificates cost money every year, and viddown costs nothing. Each release is built by GitHub Actions from the public source, so you can check exactly what went into it.

On Windows, SmartScreen may say “Windows protected your PC”. Select More info, then Run anyway.

On macOS, open your Applications folder, right-click (or Control-click) viddown and choose Open, then choose Open again. You only need to do this once.

Why isn't it on Google Play?

Google Play doesn't accept apps that download from YouTube. Install the APK from GitHub instead, or add viddown to Obtainium or IzzyOnDroid so updates arrive on their own. Android will ask you to allow installs from that source the first time.

What do you store about me?

Nothing. There's no account, and your download history stays on your device, where you can clear it in Settings. The apps send one anonymous count a day, with the app version and platform but no IP address and no links, so the numbers on this page can exist.

Is there an iPhone version?

No. Apple only allows apps like this through the App Store, and the App Store doesn't allow them.

Use it responsibly

Download only what you have the right to: your own videos, work that's licensed for reuse, or content the owner lets you save. You're responsible for what you download. viddown doesn't break DRM and won't download protected streams from services like Netflix or Disney+.

If you hold the rights to something and want to report misuse, email rashidyaseen5484@gmail.com. Every takedown request gets a reply.
